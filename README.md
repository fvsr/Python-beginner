## Git

Usando comandos no terminal para salvar um código escrito no codespaces:
- usar o comando "cd 'nome_do_diretorio'" para mudar para o diretótio onde está o código
(cada programa está em um diretório diferente para lidar com programas com mais de uma página,
ou programas que contém folhas de dados);
- pode ser usado o comando "cd .." para subir um diretório;
- usar "git add 'nome_do_programa.extensão'" para adicionar o arquivo
(no caso ele salvou todas as mudanças feitas no Codespaces);
- usar "git commit" para marcar um ponto de backup;
- usar "git push" para salvar.
